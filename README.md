# Trompeta — site publicado

Este repositório contém **apenas o build** da aplicação, que é o que o GitHub
Pages serve. O código-fonte está num repositório privado; nada aqui deve ser
editado à mão, porque o próximo deploy sobrescreve tudo.

O quadro de dedilhados da página **Escalas** foi desenhado a partir do
quadro da p. 4 do método *Da Capo*, de Joel Barbosa.
